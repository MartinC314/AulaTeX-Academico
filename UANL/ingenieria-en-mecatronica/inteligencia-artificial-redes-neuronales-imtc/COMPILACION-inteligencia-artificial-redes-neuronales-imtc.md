# Compilacion - inteligencia-artificial-redes-neuronales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-inteligencia-artificial-redes-neuronales-imtc.tex
latexmk -pdf reporte-inteligencia-artificial-redes-neuronales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-inteligencia-artificial-redes-neuronales-imtc.tex`.
- Las actividades por semana usan `reporte-inteligencia-artificial-redes-neuronales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `inteligencia-artificial-redes-neuronales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-inteligencia-artificial-redes-neuronales-imtc/p-analitico-inteligencia-artificial-redes-neuronales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

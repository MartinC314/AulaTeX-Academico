# Compilacion - adq-datos-sist-embebidos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-adq-datos-sist-embebidos-imtc.tex
latexmk -pdf reporte-adq-datos-sist-embebidos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-adq-datos-sist-embebidos-imtc.tex`.
- Las actividades por semana usan `reporte-adq-datos-sist-embebidos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `adq-datos-sist-embebidos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-adq-datos-sist-embebidos-imtc/p-analitico-adq-datos-sist-embebidos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - mecanica-vectorial-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-mecanica-vectorial-imtc.tex
latexmk -pdf reporte-mecanica-vectorial-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-mecanica-vectorial-imtc.tex`.
- Las actividades por semana usan `reporte-mecanica-vectorial-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `mecanica-vectorial-imtc.bib`.
- El programa analitico se guarda en `planeaciones-mecanica-vectorial-imtc/p-analitico-mecanica-vectorial-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

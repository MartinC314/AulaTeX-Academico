# Compilacion - sistemas-de-control-logico-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-sistemas-de-control-logico-imtc.tex
latexmk -pdf reporte-sistemas-de-control-logico-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-sistemas-de-control-logico-imtc.tex`.
- Las actividades por semana usan `reporte-sistemas-de-control-logico-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `sistemas-de-control-logico-imtc.bib`.
- El programa analitico se guarda en `planeaciones-sistemas-de-control-logico-imtc/p-analitico-sistemas-de-control-logico-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - laboratorio-de-maquinas-electricas-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-laboratorio-de-maquinas-electricas-imtc.tex
latexmk -pdf reporte-laboratorio-de-maquinas-electricas-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-laboratorio-de-maquinas-electricas-imtc.tex`.
- Las actividades por semana usan `reporte-laboratorio-de-maquinas-electricas-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `laboratorio-de-maquinas-electricas-imtc.bib`.
- El programa analitico se guarda en `planeaciones-laboratorio-de-maquinas-electricas-imtc/p-analitico-laboratorio-de-maquinas-electricas-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

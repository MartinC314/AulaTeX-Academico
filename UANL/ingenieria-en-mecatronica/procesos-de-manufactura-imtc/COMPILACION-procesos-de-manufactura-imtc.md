# Compilacion - procesos-de-manufactura-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-procesos-de-manufactura-imtc.tex
latexmk -pdf reporte-procesos-de-manufactura-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-procesos-de-manufactura-imtc.tex`.
- Las actividades por semana usan `reporte-procesos-de-manufactura-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `procesos-de-manufactura-imtc.bib`.
- El programa analitico se guarda en `planeaciones-procesos-de-manufactura-imtc/p-analitico-procesos-de-manufactura-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

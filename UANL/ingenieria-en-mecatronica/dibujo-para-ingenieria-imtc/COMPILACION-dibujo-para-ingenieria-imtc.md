# Compilacion - dibujo-para-ingenieria-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-dibujo-para-ingenieria-imtc.tex
latexmk -pdf reporte-dibujo-para-ingenieria-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-dibujo-para-ingenieria-imtc.tex`.
- Las actividades por semana usan `reporte-dibujo-para-ingenieria-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `dibujo-para-ingenieria-imtc.bib`.
- El programa analitico se guarda en `planeaciones-dibujo-para-ingenieria-imtc/p-analitico-dibujo-para-ingenieria-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

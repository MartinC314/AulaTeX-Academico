# Compilacion - optativa-iii-fundamental-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-optativa-iii-fundamental-imtc.tex
latexmk -pdf reporte-optativa-iii-fundamental-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-optativa-iii-fundamental-imtc.tex`.
- Las actividades por semana usan `reporte-optativa-iii-fundamental-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `optativa-iii-fundamental-imtc.bib`.
- El programa analitico se guarda en `planeaciones-optativa-iii-fundamental-imtc/p-analitico-optativa-iii-fundamental-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

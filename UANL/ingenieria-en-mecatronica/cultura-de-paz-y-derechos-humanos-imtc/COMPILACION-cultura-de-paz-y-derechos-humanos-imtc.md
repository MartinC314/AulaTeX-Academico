# Compilacion - cultura-de-paz-y-derechos-humanos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-cultura-de-paz-y-derechos-humanos-imtc.tex
latexmk -pdf reporte-cultura-de-paz-y-derechos-humanos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-cultura-de-paz-y-derechos-humanos-imtc.tex`.
- Las actividades por semana usan `reporte-cultura-de-paz-y-derechos-humanos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `cultura-de-paz-y-derechos-humanos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-cultura-de-paz-y-derechos-humanos-imtc/p-analitico-cultura-de-paz-y-derechos-humanos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - diseno-de-sistemas-mecatronicos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-diseno-de-sistemas-mecatronicos-imtc.tex
latexmk -pdf reporte-diseno-de-sistemas-mecatronicos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-diseno-de-sistemas-mecatronicos-imtc.tex`.
- Las actividades por semana usan `reporte-diseno-de-sistemas-mecatronicos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `diseno-de-sistemas-mecatronicos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-diseno-de-sistemas-mecatronicos-imtc/p-analitico-diseno-de-sistemas-mecatronicos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

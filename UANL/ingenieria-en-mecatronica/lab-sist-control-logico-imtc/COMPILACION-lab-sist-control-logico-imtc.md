# Compilacion - lab-sist-control-logico-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-lab-sist-control-logico-imtc.tex
latexmk -pdf reporte-lab-sist-control-logico-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-lab-sist-control-logico-imtc.tex`.
- Las actividades por semana usan `reporte-lab-sist-control-logico-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `lab-sist-control-logico-imtc.bib`.
- El programa analitico se guarda en `planeaciones-lab-sist-control-logico-imtc/p-analitico-lab-sist-control-logico-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

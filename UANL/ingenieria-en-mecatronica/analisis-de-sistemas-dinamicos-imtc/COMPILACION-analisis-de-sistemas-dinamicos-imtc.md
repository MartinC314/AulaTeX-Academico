# Compilacion - analisis-de-sistemas-dinamicos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-analisis-de-sistemas-dinamicos-imtc.tex
latexmk -pdf reporte-analisis-de-sistemas-dinamicos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-analisis-de-sistemas-dinamicos-imtc.tex`.
- Las actividades por semana usan `reporte-analisis-de-sistemas-dinamicos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `analisis-de-sistemas-dinamicos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-analisis-de-sistemas-dinamicos-imtc/p-analitico-analisis-de-sistemas-dinamicos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

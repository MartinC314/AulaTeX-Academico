# Compilacion - lab-anal-sist-dinamicos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-lab-anal-sist-dinamicos-imtc.tex
latexmk -pdf reporte-lab-anal-sist-dinamicos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-lab-anal-sist-dinamicos-imtc.tex`.
- Las actividades por semana usan `reporte-lab-anal-sist-dinamicos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `lab-anal-sist-dinamicos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-lab-anal-sist-dinamicos-imtc/p-analitico-lab-anal-sist-dinamicos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - laboratorio-de-electricidad-y-magnetismo-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-laboratorio-de-electricidad-y-magnetismo-imtc.tex
latexmk -pdf reporte-laboratorio-de-electricidad-y-magnetismo-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-laboratorio-de-electricidad-y-magnetismo-imtc.tex`.
- Las actividades por semana usan `reporte-laboratorio-de-electricidad-y-magnetismo-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `laboratorio-de-electricidad-y-magnetismo-imtc.bib`.
- El programa analitico se guarda en `planeaciones-laboratorio-de-electricidad-y-magnetismo-imtc/p-analitico-laboratorio-de-electricidad-y-magnetismo-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - servicio-social-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-servicio-social-imtc.tex
latexmk -pdf reporte-servicio-social-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-servicio-social-imtc.tex`.
- Las actividades por semana usan `reporte-servicio-social-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `servicio-social-imtc.bib`.
- El programa analitico se guarda en `planeaciones-servicio-social-imtc/p-analitico-servicio-social-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

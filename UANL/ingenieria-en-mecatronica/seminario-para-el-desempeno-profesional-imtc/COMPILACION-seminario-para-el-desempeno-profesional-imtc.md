# Compilacion - seminario-para-el-desempeno-profesional-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-seminario-para-el-desempeno-profesional-imtc.tex
latexmk -pdf reporte-seminario-para-el-desempeno-profesional-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-seminario-para-el-desempeno-profesional-imtc.tex`.
- Las actividades por semana usan `reporte-seminario-para-el-desempeno-profesional-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `seminario-para-el-desempeno-profesional-imtc.bib`.
- El programa analitico se guarda en `planeaciones-seminario-para-el-desempeno-profesional-imtc/p-analitico-seminario-para-el-desempeno-profesional-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

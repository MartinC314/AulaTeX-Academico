# Compilacion - probabilidad-y-estadistica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-probabilidad-y-estadistica-imtc.tex
latexmk -pdf reporte-probabilidad-y-estadistica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-probabilidad-y-estadistica-imtc.tex`.
- Las actividades por semana usan `reporte-probabilidad-y-estadistica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `probabilidad-y-estadistica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-probabilidad-y-estadistica-imtc/p-analitico-probabilidad-y-estadistica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

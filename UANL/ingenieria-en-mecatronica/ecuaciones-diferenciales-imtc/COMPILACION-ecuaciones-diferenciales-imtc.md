# Compilacion - ecuaciones-diferenciales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-ecuaciones-diferenciales-imtc.tex
latexmk -pdf reporte-ecuaciones-diferenciales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-ecuaciones-diferenciales-imtc.tex`.
- Las actividades por semana usan `reporte-ecuaciones-diferenciales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `ecuaciones-diferenciales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-ecuaciones-diferenciales-imtc/p-analitico-ecuaciones-diferenciales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

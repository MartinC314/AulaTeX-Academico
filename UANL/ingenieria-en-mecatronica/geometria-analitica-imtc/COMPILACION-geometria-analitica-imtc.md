# Compilacion - geometria-analitica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-geometria-analitica-imtc.tex
latexmk -pdf reporte-geometria-analitica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-geometria-analitica-imtc.tex`.
- Las actividades por semana usan `reporte-geometria-analitica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `geometria-analitica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-geometria-analitica-imtc/p-analitico-geometria-analitica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

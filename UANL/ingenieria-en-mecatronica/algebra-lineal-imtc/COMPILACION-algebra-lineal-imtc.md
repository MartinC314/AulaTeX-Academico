# Compilacion - algebra-lineal-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-algebra-lineal-imtc.tex
latexmk -pdf reporte-algebra-lineal-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-algebra-lineal-imtc.tex`.
- Las actividades por semana usan `reporte-algebra-lineal-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `algebra-lineal-imtc.bib`.
- El programa analitico se guarda en `planeaciones-algebra-lineal-imtc/p-analitico-algebra-lineal-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

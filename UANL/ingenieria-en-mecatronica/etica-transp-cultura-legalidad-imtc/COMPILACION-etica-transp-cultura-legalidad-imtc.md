# Compilacion - etica-transp-cultura-legalidad-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-etica-transp-cultura-legalidad-imtc.tex
latexmk -pdf reporte-etica-transp-cultura-legalidad-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-etica-transp-cultura-legalidad-imtc.tex`.
- Las actividades por semana usan `reporte-etica-transp-cultura-legalidad-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `etica-transp-cultura-legalidad-imtc.bib`.
- El programa analitico se guarda en `planeaciones-etica-transp-cultura-legalidad-imtc/p-analitico-etica-transp-cultura-legalidad-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - electronica-analogica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-electronica-analogica-imtc.tex
latexmk -pdf reporte-electronica-analogica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-electronica-analogica-imtc.tex`.
- Las actividades por semana usan `reporte-electronica-analogica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `electronica-analogica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-electronica-analogica-imtc/p-analitico-electronica-analogica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

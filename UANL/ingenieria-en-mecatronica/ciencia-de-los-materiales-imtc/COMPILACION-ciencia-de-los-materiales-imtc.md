# Compilacion - ciencia-de-los-materiales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-ciencia-de-los-materiales-imtc.tex
latexmk -pdf reporte-ciencia-de-los-materiales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-ciencia-de-los-materiales-imtc.tex`.
- Las actividades por semana usan `reporte-ciencia-de-los-materiales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `ciencia-de-los-materiales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-ciencia-de-los-materiales-imtc/p-analitico-ciencia-de-los-materiales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

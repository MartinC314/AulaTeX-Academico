# Compilacion - microcontroladores-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-microcontroladores-imtc.tex
latexmk -pdf reporte-microcontroladores-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-microcontroladores-imtc.tex`.
- Las actividades por semana usan `reporte-microcontroladores-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `microcontroladores-imtc.bib`.
- El programa analitico se guarda en `planeaciones-microcontroladores-imtc/p-analitico-microcontroladores-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - robotica-industrial-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-robotica-industrial-imtc.tex
latexmk -pdf reporte-robotica-industrial-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-robotica-industrial-imtc.tex`.
- Las actividades por semana usan `reporte-robotica-industrial-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `robotica-industrial-imtc.bib`.
- El programa analitico se guarda en `planeaciones-robotica-industrial-imtc/p-analitico-robotica-industrial-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - modelado-sim-sist-mecatronicos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-modelado-sim-sist-mecatronicos-imtc.tex
latexmk -pdf reporte-modelado-sim-sist-mecatronicos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-modelado-sim-sist-mecatronicos-imtc.tex`.
- Las actividades por semana usan `reporte-modelado-sim-sist-mecatronicos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `modelado-sim-sist-mecatronicos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-modelado-sim-sist-mecatronicos-imtc/p-analitico-modelado-sim-sist-mecatronicos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - calculo-integral-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-calculo-integral-imtc.tex
latexmk -pdf reporte-calculo-integral-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-calculo-integral-imtc.tex`.
- Las actividades por semana usan `reporte-calculo-integral-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `calculo-integral-imtc.bib`.
- El programa analitico se guarda en `planeaciones-calculo-integral-imtc/p-analitico-calculo-integral-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

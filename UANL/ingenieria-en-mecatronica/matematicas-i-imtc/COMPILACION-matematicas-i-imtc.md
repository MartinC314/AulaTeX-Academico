# Compilacion - matematicas-i-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-matematicas-i-imtc.tex
latexmk -pdf reporte-matematicas-i-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-matematicas-i-imtc.tex`.
- Las actividades por semana usan `reporte-matematicas-i-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `matematicas-i-imtc.bib`.
- El programa analitico se guarda en `planeaciones-matematicas-i-imtc/p-analitico-matematicas-i-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

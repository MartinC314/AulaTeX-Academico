# Compilacion - termodinamica-basica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-termodinamica-basica-imtc.tex
latexmk -pdf reporte-termodinamica-basica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-termodinamica-basica-imtc.tex`.
- Las actividades por semana usan `reporte-termodinamica-basica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `termodinamica-basica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-termodinamica-basica-imtc/p-analitico-termodinamica-basica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

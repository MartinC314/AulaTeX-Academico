# Compilacion - resp-social-desarrollo-sust-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-resp-social-desarrollo-sust-imtc.tex
latexmk -pdf reporte-resp-social-desarrollo-sust-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-resp-social-desarrollo-sust-imtc.tex`.
- Las actividades por semana usan `reporte-resp-social-desarrollo-sust-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `resp-social-desarrollo-sust-imtc.bib`.
- El programa analitico se guarda en `planeaciones-resp-social-desarrollo-sust-imtc/p-analitico-resp-social-desarrollo-sust-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - electronica-digital-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-electronica-digital-imtc.tex
latexmk -pdf reporte-electronica-digital-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-electronica-digital-imtc.tex`.
- Las actividades por semana usan `reporte-electronica-digital-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `electronica-digital-imtc.bib`.
- El programa analitico se guarda en `planeaciones-electronica-digital-imtc/p-analitico-electronica-digital-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - prototipados-rapidos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-prototipados-rapidos-imtc.tex
latexmk -pdf reporte-prototipados-rapidos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-prototipados-rapidos-imtc.tex`.
- Las actividades por semana usan `reporte-prototipados-rapidos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `prototipados-rapidos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-prototipados-rapidos-imtc/p-analitico-prototipados-rapidos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

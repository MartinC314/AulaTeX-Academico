# Compilacion - diseno-de-mecanismos-de-precision-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-diseno-de-mecanismos-de-precision-imtc.tex
latexmk -pdf reporte-diseno-de-mecanismos-de-precision-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-diseno-de-mecanismos-de-precision-imtc.tex`.
- Las actividades por semana usan `reporte-diseno-de-mecanismos-de-precision-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `diseno-de-mecanismos-de-precision-imtc.bib`.
- El programa analitico se guarda en `planeaciones-diseno-de-mecanismos-de-precision-imtc/p-analitico-diseno-de-mecanismos-de-precision-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

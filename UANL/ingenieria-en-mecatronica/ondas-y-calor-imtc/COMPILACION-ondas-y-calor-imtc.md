# Compilacion - ondas-y-calor-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-ondas-y-calor-imtc.tex
latexmk -pdf reporte-ondas-y-calor-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-ondas-y-calor-imtc.tex`.
- Las actividades por semana usan `reporte-ondas-y-calor-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `ondas-y-calor-imtc.bib`.
- El programa analitico se guarda en `planeaciones-ondas-y-calor-imtc/p-analitico-ondas-y-calor-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

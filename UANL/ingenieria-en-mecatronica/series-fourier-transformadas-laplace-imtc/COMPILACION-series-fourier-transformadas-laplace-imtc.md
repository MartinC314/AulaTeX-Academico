# Compilacion - series-fourier-transformadas-laplace-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-series-fourier-transformadas-laplace-imtc.tex
latexmk -pdf reporte-series-fourier-transformadas-laplace-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-series-fourier-transformadas-laplace-imtc.tex`.
- Las actividades por semana usan `reporte-series-fourier-transformadas-laplace-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `series-fourier-transformadas-laplace-imtc.bib`.
- El programa analitico se guarda en `planeaciones-series-fourier-transformadas-laplace-imtc/p-analitico-series-fourier-transformadas-laplace-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

# Compilacion - programacion-basica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-programacion-basica-imtc.tex
latexmk -pdf reporte-programacion-basica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-programacion-basica-imtc.tex`.
- Las actividades por semana usan `reporte-programacion-basica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `programacion-basica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-programacion-basica-imtc/p-analitico-programacion-basica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

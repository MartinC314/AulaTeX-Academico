# Compilacion - proyecto-integrador-mecatronica-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-proyecto-integrador-mecatronica-imtc.tex
latexmk -pdf reporte-proyecto-integrador-mecatronica-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-proyecto-integrador-mecatronica-imtc.tex`.
- Las actividades por semana usan `reporte-proyecto-integrador-mecatronica-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `proyecto-integrador-mecatronica-imtc.bib`.
- El programa analitico se guarda en `planeaciones-proyecto-integrador-mecatronica-imtc/p-analitico-proyecto-integrador-mecatronica-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

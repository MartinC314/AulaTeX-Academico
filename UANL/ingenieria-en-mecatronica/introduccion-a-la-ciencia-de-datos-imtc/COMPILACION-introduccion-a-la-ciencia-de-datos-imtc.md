# Compilacion - introduccion-a-la-ciencia-de-datos-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-introduccion-a-la-ciencia-de-datos-imtc.tex
latexmk -pdf reporte-introduccion-a-la-ciencia-de-datos-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-introduccion-a-la-ciencia-de-datos-imtc.tex`.
- Las actividades por semana usan `reporte-introduccion-a-la-ciencia-de-datos-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `introduccion-a-la-ciencia-de-datos-imtc.bib`.
- El programa analitico se guarda en `planeaciones-introduccion-a-la-ciencia-de-datos-imtc/p-analitico-introduccion-a-la-ciencia-de-datos-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

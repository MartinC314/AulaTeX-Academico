# Compilacion - amplificadores-operacionales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-amplificadores-operacionales-imtc.tex
latexmk -pdf reporte-amplificadores-operacionales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-amplificadores-operacionales-imtc.tex`.
- Las actividades por semana usan `reporte-amplificadores-operacionales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `amplificadores-operacionales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-amplificadores-operacionales-imtc/p-analitico-amplificadores-operacionales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

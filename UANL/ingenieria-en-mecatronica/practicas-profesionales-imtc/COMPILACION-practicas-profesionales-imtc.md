# Compilacion - practicas-profesionales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-practicas-profesionales-imtc.tex
latexmk -pdf reporte-practicas-profesionales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-practicas-profesionales-imtc.tex`.
- Las actividades por semana usan `reporte-practicas-profesionales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `practicas-profesionales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-practicas-profesionales-imtc/p-analitico-practicas-profesionales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

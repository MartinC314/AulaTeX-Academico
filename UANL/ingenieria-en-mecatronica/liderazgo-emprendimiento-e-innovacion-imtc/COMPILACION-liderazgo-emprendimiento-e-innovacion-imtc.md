# Compilacion - liderazgo-emprendimiento-e-innovacion-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-liderazgo-emprendimiento-e-innovacion-imtc.tex
latexmk -pdf reporte-liderazgo-emprendimiento-e-innovacion-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-liderazgo-emprendimiento-e-innovacion-imtc.tex`.
- Las actividades por semana usan `reporte-liderazgo-emprendimiento-e-innovacion-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `liderazgo-emprendimiento-e-innovacion-imtc.bib`.
- El programa analitico se guarda en `planeaciones-liderazgo-emprendimiento-e-innovacion-imtc/p-analitico-liderazgo-emprendimiento-e-innovacion-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

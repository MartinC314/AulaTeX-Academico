# Compilacion - control-de-sistemas-lineales-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-control-de-sistemas-lineales-imtc.tex
latexmk -pdf reporte-control-de-sistemas-lineales-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-control-de-sistemas-lineales-imtc.tex`.
- Las actividades por semana usan `reporte-control-de-sistemas-lineales-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `control-de-sistemas-lineales-imtc.bib`.
- El programa analitico se guarda en `planeaciones-control-de-sistemas-lineales-imtc/p-analitico-control-de-sistemas-lineales-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

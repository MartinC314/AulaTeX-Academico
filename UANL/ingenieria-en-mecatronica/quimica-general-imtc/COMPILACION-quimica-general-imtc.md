# Compilacion - quimica-general-imtc

Ejecutar desde esta carpeta de materia:

```powershell
latexmk -pdf reporte-quimica-general-imtc.tex
latexmk -pdf reporte-quimica-general-imtc-Actividad-1.tex
```

## Contrato de compilacion

- El archivo principal de evidencia es `reporte-quimica-general-imtc.tex`.
- Las actividades por semana usan `reporte-quimica-general-imtc-Actividad-N.tex`.
- La base bibliografica del curso se almacena en `quimica-general-imtc.bib`.
- El programa analitico se guarda en `planeaciones-quimica-general-imtc/p-analitico-quimica-general-imtc.pdf`.
- Los PDF de entrega se generan en esta misma carpeta.

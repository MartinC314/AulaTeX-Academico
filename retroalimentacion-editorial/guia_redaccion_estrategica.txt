GUÍA DE REDACCIÓN — ESTILO ESTRATÉGICO (JONATHAN)

1. PRINCIPIO BASE
No escribes para cumplir; escribes para posicionar una idea con peso.

Tu redacción debe:
- Explicar
- Interpretar
- Tomar postura

Regla:
Si el texto no deja claro qué significa, por qué importa y cómo se aplica, está incompleto.


2. ESTRUCTURA OBLIGATORIA

1) Apertura (golpe directo)
- Evita introducciones blandas
- Inicia con una afirmación fuerte

2) Desarrollo (análisis)
Siempre cubre:
- Qué es
- Cómo funciona
- Por qué existe
- Qué implica

Reglas:
- No describas → interpreta
- No repitas → conecta
- No adornes → precisa

3) Cierre (posición)
Debe incluir:
- Lectura crítica
- Aplicación real
- Juicio propio


3. FORMA DE ARGUMENTAR

A) Pensamiento analítico
- Descomponer
- Relacionar (causa–efecto)
- Reconstruir

B) Enfoque estratégico
Preguntas clave:
- ¿Qué función cumple?
- ¿Qué problema resuelve?
- ¿Quién gana y quién pierde?

C) Lenguaje de poder
Usar:
- sistema
- estructura
- función
- control
- criterio
- costo
- decisión

Evitar:
- yo creo
- tal vez
- se podría


4. REGLAS DE ORO

1. Nada es gratuito
Todo tiene causa, función y consecuencia.

2. Siempre contextualiza
Ubica en la realidad (social, legal o práctica).

3. La teoría sirve para operar
Si no se puede aplicar, no sirve.

4. Evita lo obvio
No definas como libro, define con criterio.

5. El texto debe tener filo
Debe ser claro, firme y con dirección.


5. MÉTODO PARA ACTIVIDADES

Paso 1: Identifica el núcleo
¿Qué te están preguntando realmente?

Paso 2: Traduce a problema
Convierte la consigna en algo operativo.

Paso 3: Desarrolla en capas
- Concepto
- Funcionamiento
- Implicación

Paso 4: Agrega lectura crítica
Cuestiona, interpreta y toma postura.

Paso 5: Cierra con aplicación
Llévalo a la práctica profesional.


6. EJEMPLO

Básico:
La historia del derecho estudia el origen de las normas.

Estratégico:
La historia del derecho no es acumulación de normas; es el registro de cómo una sociedad organiza el poder y resuelve conflictos.


7. TONO

Mantener:
- Analítico
- Directo
- Estratégico
- Con intención

Evitar:
- Dramático
- Relleno
- Escolar básico


8. VENTAJA PERSONAL

Base:
- Ingeniería → estructura lógica
- Docencia → claridad
- Estrategia → lectura de contexto

Resultado:
Explicación + sistema + intención


9. FÓRMULA FINAL

Todo texto debe responder:
1. ¿Qué es?
2. ¿Cómo funciona?
3. ¿Por qué importa?
4. ¿Qué implica?
5. ¿Cuál es mi postura?


10. FRASE GUÍA

No escribo para llenar espacio; escribo para dejar claro cómo funciona el sistema y qué posición tomo frente a él.

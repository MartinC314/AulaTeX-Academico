# AulaTeX

Bitacora y salidas de ciclos incrementales de AulaTeX.

Esta carpeta registra resultados del agente `investigar -> compilar -> evaluar`
sin mezclar automaticamente borradores LLM dentro de las carpetas de materia.

Documentos de diseno operativo:

- `agente-verdadero-contrato-operativo.md`: contrato de `estado-agente.json`,
  politica de decision y criterios minimos para un bucle real por actividad.
- `ingenieria-inversa-agentica.md`: enfoque de diseño por ingeniería inversa o
  recursiva desde el resultado esperado hacia agentes, etapas, memoria y herramientas.
- `prototipo-actividad-1-agentica.md`: especificacion accionable del prototipo cerrado
  para validar Actividad 1 con contrato objetivo, bucles acotados, memoria y matriz de pruebas.
- `filosofia-del-derecho-flujo-agentico.md`: analisis operativo de actividades,
  planeaciones, bibliografia, referencias y flujo agentico para Filosofia del Derecho.

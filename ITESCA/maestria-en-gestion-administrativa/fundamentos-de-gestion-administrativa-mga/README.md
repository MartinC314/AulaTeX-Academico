# Fundamentos de Gestión Administrativa

Asignatura básica de la Maestría en Gestión Administrativa del ITESCA.

- Clave: `ACF-0901`.
- Créditos: 6.
- Competencia general: aplicar conceptos, herramientas y enfoques teóricos de la gestión, así como analizar y evaluar decisiones.

## Estructura canónica

- `reporte-fundamentos-de-gestion-administrativa.tex`: reporte base heredado.
- `reporte-fundamentos-de-gestion-administrativa-mga.tex`: plantilla maestra institucional ITESCA.
- `reporte-fundamentos-de-gestion-administrativa-plantilla-actividad.tex`: base compartida de las actividades 6 a 10; no se compila directamente.
- `presentacion-fundamentos-de-gestion-administrativa-mga.tex`: presentación maestra institucional.
- `fundamentos-de-gestion-administrativa.bib`: bibliografía local verificable.
- `programa-analitico-fundamentos-de-gestion-administrativa.md`: encuadre editorial.
- `planeaciones-fundamentos-de-gestion-administrativa/`: planeaciones y consignas.
- `referencias-fundamentos-de-gestion-administrativa/`: fuentes, lecturas y documentos de apoyo.
- `assets-fundamentos-de-gestion-administrativa/`: imágenes o evidencias visuales específicas.

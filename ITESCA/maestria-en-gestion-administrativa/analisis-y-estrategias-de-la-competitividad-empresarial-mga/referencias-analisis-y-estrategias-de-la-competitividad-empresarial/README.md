# Referencias - Competitividad Empresarial

Carpeta para resguardar fuentes oficiales, diagnosticos sectoriales, matrices,
casos empresariales y evidencia auxiliar de la materia.

## Convenciones

- Registrar toda fuente final en `../analisis-y-estrategias-de-la-competitividad-empresarial.bib`.
- Separar datos estadisticos, marco normativo, casos, matrices y lecturas teoricas.
- Cuando se use un indicador competitivo, anotar unidad, periodo, fuente y criterio.
- Para estrategias, conservar el diagnostico base y la metrica de seguimiento.

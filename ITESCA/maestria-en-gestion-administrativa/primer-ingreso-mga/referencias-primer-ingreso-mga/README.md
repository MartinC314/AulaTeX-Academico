# Referencias - Primer ingreso MGA

Carpeta para conservar fuentes de apoyo, notas de lectura, planeaciones,
capturas, cuestionarios originales y evidencia auxiliar de las actividades de
primer ingreso.

## Convenciones

- Registrar fuentes finales en `../primer-ingreso-mga.bib`.
- Guardar documentos institucionales con nombres descriptivos y sin espacios
  innecesarios cuando sea posible.
- Si se extrae informacion de una fuente, agregar nota breve con fecha de
  consulta y funcion dentro de la actividad.
- Separar evidencia de entrega final de materiales de trabajo.

## Fuentes iniciales registradas

- Sitio institucional ITESCA: `itescaSitioWeb`.
- Oferta oficial Maestria en Gestion Administrativa: `itescaMGAOferta`.
- Materiales de administracion, mercadotecnia y fundamentos administrativos
  usados en las actividades 1 y 2.

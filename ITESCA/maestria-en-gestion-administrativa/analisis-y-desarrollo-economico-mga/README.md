# Analisis y Desarrollo Economico

Materia de la Maestria en Gestion Administrativa vinculada con el tronco comun
de formacion economica, diagnostico territorial y toma de decisiones.

## Pauta editorial

Los productos de esta materia deben leer el desarrollo economico como relacion
entre territorio, sectores productivos, productividad, empleo, bienestar,
desigualdad, instituciones y capacidad de gestion.

El estilo esperado es de posgrado: no basta describir indicadores. Cada entrega
debe explicar que problema economico se observa, que evidencia lo sostiene, que
actores intervienen y que decision administrativa o politica publica se puede
derivar para mejorar una organizacion, sector o territorio.

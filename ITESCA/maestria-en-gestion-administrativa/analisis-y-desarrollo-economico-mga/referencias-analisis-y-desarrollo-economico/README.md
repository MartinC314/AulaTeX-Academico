# Referencias - Analisis y Desarrollo Economico

Carpeta para resguardar fuentes oficiales, tabulados, notas de coyuntura,
indicadores territoriales y evidencia auxiliar de la materia.

## Convenciones

- Registrar toda fuente final en `../analisis-y-desarrollo-economico.bib`.
- Separar fuentes institucionales, indicadores economicos y materiales de clase.
- Cuando se use un dato, anotar periodo, unidad, cobertura geografica y fuente.
- Para diagnosticos territoriales, conservar el indicador base y la lectura critica.

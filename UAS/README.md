# Universidad Autónoma de Sinaloa (UAS)

Nodo institucional de AulaTeX-Académico para organizar plantillas, fuentes y entregables por programa y asignatura.

## Materias disponibles

- `licenciatura-en-contaduria-uas/investigacion-aplicada-a-la-contaduria/`

## Convención

Cada materia conserva sus plantillas, bibliografía, planeaciones, referencias, memoria editorial y productos derivados. Los datos académicos no confirmados se mantienen como campos editables; no se sustituyen con supuestos.

La compilación se ejecuta desde la raíz de `AulaTeX-Academico` conforme al `COMPILACION.md` de cada materia.

# Recursos institucionales UAS

Coloque aquí únicamente recursos cuya procedencia y autorización de uso estén verificadas.

- `marca-uas-provisional.tex`: marca tipográfica auxiliar para compilar las plantillas mientras se obtiene un logotipo oficial autorizado.
- `marca-uas-provisional.pdf`: archivo derivado generado al compilar el anterior.

La marca provisional no es el escudo ni el logotipo oficial de la Universidad Autónoma de Sinaloa.
